Apcosys предоставляет вам **неисключительную, непередаваемую, отзывную, ограниченную лицензию** на доступ к API и его использование для получения Данных при соблюдении настоящего Соглашения и Условий использования Apcosys. Различные тарифные планы предусматривают разные права на использование Данных:

- **Тарифы Personal и Free:** Данные предназначены исключительно для личного некоммерческого использования; их нельзя перепродавать или передавать другим лицам.
- **Тарифы Business и Enterprise:** Данные можно использовать в коммерческих целях; перепродажа регулируется дополнительными условиями.

Без прямо выраженного письменного разрешения Apcosys вы не вправе перепродавать, сублицензировать, распространять или публично демонстрировать Данные.
