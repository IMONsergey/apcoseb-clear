# Apcosys 資料收集政策

_Last updated: August 4, 2025_

## Apcosys 收集哪些資料及如何收集

Apcosys 應用程式僅透過**非侵入式**方法，收集**公開且可從外部存取的資料**。我們的演算法使用標準化的開放網路協定查詢主機，並取得特定屬性。收集的資料範例包括：

- **開放連接埠：**  
  網路應用程式使用特定連接埠進行通訊，例如用於網頁流量的 TCP 連接埠 80 或 443。安全最佳實務建議僅開放必要的連接埠。這些連接埠背後的服務通常會分享稱為 **「橫幅（banners）」** 的公開中繼資料。

- **SSL 憑證：**  
  這些憑證可啟用加密通訊，並包含公開金鑰、網域名稱及憑證簽發者詳細資料等**公開資訊**，以確保安全連線。

- **Whois 資料庫：**  
  這包含網域、註冊人及註冊商的**公開資訊**；網際網路名稱與數字位址分配機構（ICANN）要求這些資訊可透過 Whois 目錄供公眾查閱。

這些資料類型的收集屬於非侵入式行為，因為任何人都可使用標準網路工具公開存取它們。

## 目的

我們的目標是協助使用者進行**研究、行銷及提升網路安全**。我們希望促成更安全、更穩健的網際網路，並遵循 <https://www.mozilla.org/en-US/about/manifesto/> 等文件所述的原則。Apcosys 透過提供協助知情決策的工具，支持這項願景。

**未經明確同意且確認所有權**，我們**不會**使用侵入式技術、進行滲透測試、規避安全措施或存取私人資料。應您的要求，我們可使用侵入式方法對您擁有的主機進行詳細掃描，結果僅提供給您。

## 法律遵循

Apcosys 僅收集公開資料，不進行未經授權的存取，以遵守包括**美國《電腦詐欺及濫用法》（CFAA）** 在內的適用法律。我們的營運設計旨在尊重數位資產的**機密性、完整性及可用性**。

## 如何將資訊設為非公開

如果 Apcosys 顯示您希望保密的主機資訊，您可透過**重新設定軟體**來限制存取。使用 Apcosys **重新掃描您的主機**，並驗證安全邊界的變更。
